# Задача агенту на ПК: связать аккаунты и убрать только из выбранного списка

Репозиторий: Egorka-777/myvideopril. Ветка: feat/accounts-sync-lists-20261009.
Основа этой доработки — полностью готовая картотека ebe4f0f1b392b38628514a88d0c32f80e7bcb5e1 из feat/accounts-library-20261008. Не заменяй рабочее приложение старой main: на ПК могут уже стоять более новые исправления сцен и сборки роликов.

1. Найди фактически запускаемый VideoBatch.exe, его исходники и текущую рабочую ветку. Проверь локальные изменения. При закрытом приложении сохрани копию исполняемой папки, пользовательских настроек, vault с bak, профилей, шаблонов, истории и материалов. Не коммить реальные данные.
2. Выполни `git fetch origin feat/accounts-sync-lists-20261009`. Посмотри весь diff от ebe4f0f1b392b38628514a88d0c32f80e7bcb5e1 до origin/feat/accounts-sync-lists-20261009. Если картотека уже установлена, перенеси весь новый диапазон через `git cherry-pick ebe4f0f1b392b38628514a88d0c32f80e7bcb5e1..origin/feat/accounts-sync-lists-20261009` в ветку текущего приложения. Если картотека не установлена, диапазон начинается с b8aed136162404b19911ddf2f76bb0cde17276c1. Если часть изменений уже перенесена, сравни содержимое и перенеси только отсутствующее. Не выбирай только последний коммит.
3. Сохрани обе функции при конфликтах в AppShell, NavigationService, ProfileCatalog, рабочих панелях и csproj. Compile Include для AssemblyInventory.cs и уже установленные исправления видеосборки должны остаться. Собери `dotnet build VideoBatch.csproj -c Release -p:ApplicationIcon=`.
4. На Windows запусти статические проверки VideoBatch.AccountLibraryTests: RunStoreTests, RunWorkbookTests, RunUiTests, RunSyncTests, RunScopedRemovalTests, RunLinkedUiTests. Они работают с временными настройками и синтетическими данными. Проверь существующие регрессии сборки и обработки видео. Обнови именно запускаемый EXE и его config; не заменяй пользовательские настройки пустыми настройками из сборки.
5. Запусти приложение под тем же пользователем Windows, с реальным действующим settings.xml. Стандартный путь — %LOCALAPPDATA%\VideoBatchDesktop\settings.xml; уточни фактический Store.Config, если запуск использует иной путь. Открой «Аккаунты»: оно само создаст/свяжет карточки из текущих YouTubeChannels и TikTokAccounts. Сохранятся существующие accounts.vault и ручные поля. Сравни количество исходных строк со связями Sources на карточках, а не только с количеством карточек: один канал с совпадающей ссылкой может присутствовать в нескольких списках.
6. Проверь названия, площадки, RU/EN и ссылку YouTube, связь с браузерным ProfileId. Не объединяй разные каналы лишь по названию или ProfileId. IP не является полноценным прокси, RU/EN не является страной. В загрузочных настройках нет паролей, ссылки на покупку и полного прокси: отсутствие должно остаться явно отмеченным в карточке. Сессия браузера не даёт основания придумывать пароль. Для TikTok существующая строка может быть автоматически перенесённой привязкой браузера из YouTube; проверь настоящее имя и ссылку вручную.
7. Если пользователь предоставил локальный Excel или другие реальные источники, заполняй только однозначно соответствующие карточке сведения через форму «Дополнить»/импорт. Не угадывай недостающие поля. Если раздел сообщает «не связаны», разбери совпадающие ссылки локально до объединения. Отчёт: количество строк YouTube/TikTok, количество карточек/связей и перечень недостающих полей по названиям аккаунтов; пароли, логины целиком и прокси в отчёт не выводи.
8. Проверь на синтетических настройках: правый клик на YouTube RU → «Убрать из списка RU» не убирает EN или TikTok; аналогично TikTok EN не убирает RU. Карточка и её сведения остаются, удалённая привязка отмечена. TikTok не должен автоматически возвращать удалённую строку в тот же список. На реальных аккаунтах ничего не удаляй ради проверки.
9. Перезапусти приложение и проверь сохранение карточек и ручных сведений без дублей. Сообщи установленный коммит, полный путь запускаемого EXE, число связанных строк и каких сведений не хватает. Если данных нет в предоставленных источниках, оставь их для ручного заполнения пользователем.
