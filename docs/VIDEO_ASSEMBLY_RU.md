# Моя студия: сцены и объекты

Студия собирает ролики из готовых картинок, коротких видео и музыки. Текстовые заголовки здесь тоже картинки: отдельный редактор текста не нужен.

## Первый запуск

1. **Видео** слева → **+ Добавить файлы**: загрузите общий запас фонов.
2. Выберите сцену. В ней уже есть **Объект 1**. Нажмите **+ Изображения** и выделите все варианты картинки для этого места. Один объект показывает **одну** картинку в каждом ролике; остальные файлы являются вариантами для следующих роликов.
3. Передвиньте объект на холсте, задайте размер. Можно сначала поставить пустой объект, затем загрузить картинки — размещение сохранится.
4. Если одновременно нужна ещё одна картинка, нажмите **+ Объект**. У него будут свои варианты, размер и положение. Например, в последней сцене: **Объект 1 — постоянная CTA**, **Объект 2 — меняющаяся картинка с текстом**.
5. По желанию загрузите треки через **Музыка**. Один трек звучит непрерывно через все сцены ролика; следующий ролик получает другой вариант, пока есть неиспользованные треки в этой сборке. Без музыки получится ролик без звука. Звук исходных видео не сохраняется.
6. Внизу выберите **формат → переход → количество → Собрать**. **Результаты** открывает папку готовых MP4. Настоящий MP4 для проверки можно посмотреть через **⋯ → Посмотреть пример ролика**.

Новая студия содержит **четыре сцены по пять секунд**. Длительность меняется ползунком. Плюс между сценами вставляет новую сцену, стрелки меняют порядок. **Правый клик → Удалить сцену** убирает сцену из ролика, сохраняя её материалы на диске. Можно удалить все сцены, включая последнюю, или добавить до 12. Пустая студия сохраняется; сборка отключена, пока вы не нажмёте плюс и не добавите сцену.

## Объекты вместо отдельных слоёв для каждого файла

В каждой сцене можно создать до восьми объектов. Карточка объекта показывает количество вариантов и режим. Чтобы выбрать скрытый объект, нажмите **⋯** в строке объектов. Правый клик на объекте позволяет загрузить варианты, включить ограничения без повторов или удалить объект. Удаление объекта сохраняет его файлы на диске; сцена может остаться без картинок.

**+ Изображения** добавляет файлы в выбранный объект. **Варианты** открывает его картинки. Нажатие миниатюры показывает её для примерки. Это не превращает все варианты в отдельные объекты и не закрепляет их автоматически.

- **Менять**: в следующем ролике используется другой вариант, пока запас позволяет. После использования всех вариантов картинки могут повторяться в новых сочетаниях. Точная связка видео, картинок и музыки повторно не выпускается.
- **Постоянный**: выбранная картинка используется в каждом ролике. Для CTA загрузите одну картинку или выберите нужную миниатюру и нажмите **Постоянный**. Переименование файла не сбрасывает закрепление. Если он исчез, сборка попросит выбрать новый.
- **Без повторов** в меню объекта: каждая картинка используется только один раз, включая прошлые сборки этой студии. При исчерпании запасов выпуск ограничивается. Например, при запасах 11, 11 и 12 картинок можно собрать максимум 11 роликов без повторного использования картинок. В режиме **Менять** разные сочетания позволяют выпустить больше.

При первой загрузке одного изображения объект становится постоянным; при загрузке нескольких — меняющимся. Если вы явно выбрали режим кнопкой, дальнейшая загрузка его сохраняет.

Для вашего примера с тремя сценами нужны: один объект в первой, один во второй, два в третьей. Несколько картинок, видимых одновременно в одном месте, обычно означают несколько отдельных объектов. Удалите лишний объект через правый клик, оставьте один объект с пачкой вариантов.

## Видео, музыка и комбинации

Кнопка **Общие видео / Свои видео** находится прямо у названия выбранной сцены. Нажмите её и выберите **+ Загрузить для этой сцены**, чтобы добавить отдельную пачку. Кнопка **Свои видео · N** показывает её размер. **Посмотреть свои видео** открывает файлы этой пачки.

Пачка принадлежит самой сцене: добавление других сцен, перестановка и повторное открытие студии не меняют привязку. Можно дать первой и второй сценам разные пачки, а остальным оставить общие видео. При переключении на **Общие видео** свои файлы сохраняются; их можно снова включить.

Общие видео выбираются для сцен в режиме **Общие видео**. При достаточном запасе в одном ролике используются разные фоны; при нехватке допускаются повторы. В следующих роликах меняются и картинки объектов, и фоны в соответствующих сценах, и музыка. Порядок сцен и расположение объектов остаются такими, как вы их настроили. Роли объектов не переставляются: CTA остаётся на месте.

Длинный фон обрезается, короткий зацикливается. Для отдельного запаса торговли выберите **Свои видео** у этой сцены. Пустая своя папка не подменяется общим фоном: добавьте файлы или явно выберите **Общие видео**. При открытии старой студии активные отдельные видеопулы сохраняются; прежние пустые источники остаются в режиме общих видео.

В одной сборке перемешивание учитывает уже выбранные варианты, чтобы не брать снова ту же картинку, пока у объекта остаются другие варианты. При ограничениях истории или исчерпании сочетаний выбор может быть уже. Копии одного файла и переименования считаются одним материалом, а разные точки начала одного видео не создают новую комбинацию.

**Доступно … связок · за раз до … роликов** пересчитывается после изменения материалов и настроек. Кнопки **− / +** и ввод числа ограничены доступным запасом. Искусственного ограничения в 1000 роликов нет; поддерживается число до 2 147 483 647. Программа готовит большую очередь порциями, её можно остановить. Количество связок и лимит сборки различаются, если используются картинки **Без повторов**.

Маленькие наборы перебираются точно. Большой общий видеопул считается формулой с проверкой истории и рецептов. Если старые рецепты потеряны или пулы имеют сложные пересечения, надпись **До …** означает верхнюю границу. При сборке история всё равно защищает от прежних связок. Предпросмотр историю не расходует.

## Переход и формат

Кнопка перехода находится внизу рядом с форматом. Доступны плавный переход, приближение, отдаление, втягивание, свайп и отсутствие перехода. В этом же выборе задаётся скорость.

Переход применяется ко всему готовому кадру: **фон и все его картинки двигаются вместе**, музыка продолжается без перехода. Картинки, установленные до конца сцены, остаются в её исходящем переходе. Холст показывает размещение; движение проверяйте в MP4.

Основной формат — **9:16, 1080×1920** для вертикальных TikTok/Shorts. Для быстрой проверки есть **9:16, 720×1280**. Также доступны 4:5, 3:4, 1:1 и 16:9. Фон заполняет весь кадр с сохранением пропорций и обрезкой краёв; картинки сохраняют пропорции и прозрачность. После смены формата проверьте размещение.

## Сохранение и обновление

Материалы копируются в `Материалы-сборки` рядом с приложением; оригиналы остаются на месте. У каждой сцены отдельная папка, у каждого объекта — свой источник вариантов. Можно добавлять файлы прямо в эти папки, затем открыть или обновить студию.

Размеры, позиции, режимы, длительности, формат и переход сохраняются автоматически в `assembly-template.xml` в существующей папке данных VideoBatch. Замена и очистка вариантов не сбрасывают размещение. **Заменить пачку** меняет источник, сохраняя прежние файлы; **Очистить** отключает старые материалы, сохраняя их на диске. Для освобождения места используйте **Открыть папку** и удалите ненужные файлы вручную.

При первом обновлении на объекты создаётся копия `assembly-template.xml.before-objects-*.xml`. Положения, источники, ID истории и ограничения **Без повторов** сохраняются. Старые закреплённые объекты с несколькими разными картинками переводятся в **Менять**, чтобы пачка участвовала в комбинациях. Постоянная CTA с одной картинкой остаётся постоянной. Если вы специально закрепляли одну картинку из большой пачки, выберите её и снова нажмите **Постоянный**. Старые лишние слои не объединяются и не удаляются автоматически — проверьте число объектов.

При переходе совсем старой студии дополнительно создаётся резервная копия `.before-packs-*.xml`. TXT в новом интерфейсе не используется.

Рядом с каждым готовым MP4 сохраняется `.assembly.xml` с точным набором материалов. Отмена не расходует незавершённый ролик; уже готовые результаты остаются в истории.

## Агенту на ПК

Обновление находится в ветке `feat/assembly-scene-video-routing-20261008`. Актуальный `main` на момент начала работы — `b8aed136162404b19911ddf2f76bb0cde17276c1`; ветка также включает предыдущую доработку объектов `0f797152d75a56bcc850e08dcbd95cf3c0fc3ebb`, которая ещё не была в main. Переносить старую ветку отдельно не нужно.

Сохраните локальные изменения и сделайте резервную копию запускаемых файлов, шаблона и истории. Подтяните `main` и перенесите изменения этой ветки, сохранив последующие изменения основного приложения. Соберите `VideoBatch.csproj` в Release и выполните проверки из `.github/workflows/video-assembly.yml`, либо используйте готовый проверенный Windows-комплект этой ветки. Обновите **фактически запускаемый EXE**, его конфигурацию и необходимые инструменты. EXE в корне репозитория может быть старым. Не заменяйте папку данных пользователя, профили, материалы и историю.

Проверьте `SOURCE_COMMIT.txt` готового комплекта и путь ярлыка. При первом запуске откройте существующую студию: первая сцена — один объект с 11 вариантами, вторая — один с 11, третья — постоянная CTA и второй объект с 12 меняющимися вариантами. Лишние объекты удаляйте через интерфейс только после проверки их содержимого. Не переносите материалы из двух разных объектов в одну общую пачку автоматически.

Проверьте пользовательский сценарий: удалите третью сцену через меню **⋯** или правый клик, оставьте две. Для первой загрузите свою пачку видео, для второй — другую. Соберите два ролика: каждое видео должно происходить из пачки своей сцены, музыка непрерывная, картинки переходят вместе с фоном. Переставьте сцены, вставьте новую между ними, закройте и откройте студию — источники должны следовать за своими сценами. Отдельно проверьте удаление до нуля сцен и добавление первой обратно. Удаление сохраняет материалы на диске. Старая ошибка «Доступ к ликвидированному объекту: ContextMenuStrip» исправляется отложенной обработкой выбора и закрытия меню.

Соберите три ролика и проверьте разные картинки, разные фоны при достаточном запасе, непрерывную музыку и совместное движение фона с картинками. Закройте и откройте приложение: позиции и режимы должны сохраниться. Чистую новую студию можно создать через **⋯ → Новая студия · 4 сцены**; существующую не удалять.

Для сборки нужны настоящие FFmpeg и FFprobe. Windows CI компилирует приложение, проверяет интерфейс и реальные MP4, затем упаковывает EXE, конфигурацию и инструменты.
