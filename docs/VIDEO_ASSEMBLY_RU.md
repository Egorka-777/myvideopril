# Моя студия: сборка из пачек

На основном экране нет текстовых заголовков и редактора текста. Используются готовые изображения PNG/JPG/JPEG/BMP/GIF, видео и музыка.

## Первый ролик

1. Нажмите **Видео → + Добавить файлы**. Можно выделить сразу всю пачку. Это общий запас фонов для всех сцен.
2. Нажмите **Файлы** рядом со сценой 1 и добавьте её картинки. Повторите для остальных сцен. Пустая пачка означает сцену без картинки и не блокирует сборку.
3. Выберите сцену. Фон появляется автоматически. Передвиньте картинку мышью, измените её размер ползунком. Это расположение применяется ко всей пачке этой сцены.
4. По желанию добавьте пачку через **Музыка**. На каждый ролик выбирается один трек, непрерывно звучащий через все сцены. Без музыки получится ролик без звука; исходный звук видеоклипов не сохраняется.
5. Установите длительность сцен, формат и количество роликов. Нажмите **Посмотреть ролик**, затем **Собрать ролики**.

Новая студия начинается с **четырёх сцен по пять секунд**, всего 20 секунд. Длительность меняется ползунком. Сохранённая ранее студия сохраняет своё количество сцен, файлы и расположение. Чтобы начать с четырёх пустых сцен, выберите **⋯ → Новая студия · 4 сцены**; предыдущая студия сохраняется отдельным XML.

## Пачки остаются в приложении

Материалы копируются в папку `Материалы-сборки` рядом с приложением. Оригиналы остаются на месте. Настройки и расположение сохраняются автоматически в `assembly-template.xml` внутри существующей папки данных VideoBatch.

При следующем открытии не нужно заново загружать картинки, видео, музыку и расставлять их. Можно также положить файлы непосредственно в папку пачки; студия прочитает их при открытии/обновлении.

Для каждой сцены создаётся отдельная папка. Плюс между сценами вставляет новую сцену и создаёт её папку. Стрелки перемещают сцену вместе с её пачками и расположением. **Правый клик → Удалить сцену** убирает её из ролика; файлы этой сцены остаются на диске.

## Работа с файлами

- **+ Добавить файлы** добавляет материалы в выбранную пачку. Можно перетащить файлы в кнопки Видео, Музыка или + Файлы и в список файлов.
- **Заменить пачку** переключает сцену на новую пачку, сохраняя предыдущие файлы, размеры и координаты. Для закреплённой пачки новая первая картинка становится закреплённой. Отмена выбора ничего не меняет.
- **Очистить** создаёт пустую пачку и отключает предыдущую от сборки; предыдущие файлы сохраняются. Для освобождения места их можно удалить вручную через **Открыть папку**.
- В окне файлов сцены можно выбрать любую картинку для примерки. Позиция относится ко всей пачке, а для сборки используется заданный режим.
- **+ Ещё поверх** добавляет вторую пачку в ту же сцену, например скриншот бота и картинку с призывом. Каждая пачка получает своё расположение. Новая пачка создаётся после выбора файлов.

## Как выбираются материалы

В окне файлов сцены доступны три режима:

- **Перемешивать** — случайное изображение из пачки на каждый ролик. Изображение можно использовать в разных комбинациях.
- **Закрепить CTA / Закреплена** — выбранная картинка сохраняется по содержимому и используется во всех роликах. Сначала нажмите на нужную картинку в пачке, затем закрепите её. В закреплённой пачке нажатие другой картинки меняет закрепление. Переименование файла его не сбрасывает. Если файл исчез, сборка попросит выбрать новый; подмена другим файлом не происходит.
- **Без повторов** — содержимое картинки используется только один раз, с учётом прошлых сборок этой студии. Переименование не делает её новой. Если запас закончился, программа объяснит причину и соберёт только доступное количество.

Режим выбранной картинки доступен прямо под холстом: **Меняется**, **Закреплена**, **Без повторов**. Для последней сцены закрепите верхнюю CTA, выберите вторую картинку и оставьте её в режиме **Меняется**.

Новые пачки по умолчанию перемешиваются. Уже сохранённые ограничения без повторов сохраняются при обновлении.

Общий запас видео используется во всех сценах. При достаточном запасе программа выбирает разные фоны внутри ролика; если не хватает — допускает повтор. Длинное видео обрезается, короткое зацикливается до нужной длительности. Если для торговли нужен отдельный запас, откройте **⋯ выбранной сцены → Видео только для этой сцены**. Пустая отдельная пачка использует общие видео.

Точные сочетания видео, картинок и музыки не выпускаются повторно в одной студии. Изменение случайного времени начала клипа не считается новым сочетанием. Нельзя получить больше разных сочетаний, чем позволяют материалы; об этом программа сообщает. Предпросмотр не расходует картинки и не записывает выпуск в историю.

## Переходы и количество связок

Кнопка **Переход** находится рядом с количеством роликов на основном экране. Доступны плавный переход, приближение, отдаление, втягивание и свайп, а также вариант без перехода. В этом же меню меняется скорость. Эффект применяется ко всему кадру с уже наложенными картинками. **Посмотреть ролик** показывает настоящий MP4 с выбранным эффектом; статичный холст отвечает только за размещение.

Строка **Доступно … связок · за раз до … роликов** пересчитывается в фоне после изменения материалов, режимов и длительности. Файлы считаются по содержимому: копии, переименования и разные точки начала одного видео не увеличивают запас. Учитываются длина фонов, музыка, закрепление, история и общие пачки картинок без повторов. Число связок и лимит одной пачки могут различаться: 100 сочетаний не дают 100 выпусков, если картинок без повторов осталось только пять.

Для небольших наборов все связки перебираются точно, поэтому остаток истории известен. Большие общие видеопулы считаются формулой с проверкой сохранённых рецептов. Если старые рецепты потеряны или большие пулы имеют сложные пересечения, показывается **До …**, то есть верхняя граница. История всё равно защищает от выпуска прежних связок. Лимит одной сборки — 1000 роликов. Нельзя обещать миллионы доступных выпусков только на основании числа файлов.

Все позиции, размеры, длительности, режимы и переход сохраняются автоматически, в том числе при закрытии приложения. Замена или очистка пачки не сбрасывает размещение. Чужие изменения `main`, включая сокращение длинных имён файлов при импорте, сохранены.

## Формат

Основной формат — **9:16, 1080×1920** для вертикальных TikTok/Shorts. Для более быстрой проверки есть **9:16, 720×1280**. Также доступны 4:5, 3:4, 1:1 и 16:9. 3:4 — дополнительный формат, не отдельное требование TikTok.

Фон заполняет весь кадр с сохранением пропорций и обрезкой лишнего по краям. Изображения сохраняют пропорции и прозрачность. При переключении формата проверьте расположение в предпросмотре.

## Обновление и ошибки

Старый шаблон автоматически переводится на пачки. Перед этим создаётся копия `assembly-template.xml.before-packs-*.xml`. Настоящие картинки, позиции, режимы без повторов и ID истории сохраняются. Пустые старые источники больше не являются обязательными. TXT не добавляется и не используется в новой студии; рендерер TXT сохранён только для старых программных шаблонов.

Для работы нужны настоящие FFmpeg и FFprobe. Сборка Windows в GitHub Actions проверяет приложение, создаёт реальные MP4 и упаковывает EXE, конфигурацию, FFmpeg/FFprobe и существующие вспомогательные инструменты. EXE в корне репозитория может быть старым: используйте результат новой сборки.

Готовые MP4 находятся в выбранной папке результатов. Рядом сохраняется `.assembly.xml` с точным набором материалов. Сборку можно остановить. Незавершённые результаты не расходуют картинки; уже готовые результаты остаются в истории.

## Агенту на ПК

Обновление находится в ветке `feat/assembly-polish-transitions-20261007`, созданной от `main` на коммите `d42f8ecdf8a4ead10dc7cd5fe5312ab7429371eb`.

Сохраните локальные изменения и резервную копию запускаемых файлов. Подтяните актуальный `main` и перенесите изменения ветки, сохранив последующие изменения основного приложения. Соберите `VideoBatch.csproj` в Release, выполните проверки из `.github/workflows/video-assembly.yml`, обновите фактически запускаемый EXE вместе с его конфигурацией. Не заменяйте папку данных пользователя и его материалы.

На первом запуске проверьте существующую студию, импорт пачек, повторное открытие приложения и сборку MP4. Новую чистую студию из четырёх сцен можно создать через меню; старую не удалять.
