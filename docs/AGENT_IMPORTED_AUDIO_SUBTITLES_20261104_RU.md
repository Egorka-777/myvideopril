# Субтитры из загруженной озвучки

Добавлено локальное распознавание Faster-Whisper small. Озвучка больше не обязана создаваться через ElevenLabs внутри приложения. Можно импортировать свои MP3, WAV, M4A, FLAC и другие форматы, читаемые движком, в общую озвучку или в отдельные сцены. Распознаётся только выбранная озвучка, музыка не используется как источник субтитров.

## Как пользоваться

1. Добавить готовые файлы озвучки обычным способом. После самостоятельной нарезки длинной записи добавить уже нарезанные файлы.
2. Открыть «Субтитры» → «Распознать аудио» → «Распознать». Обрабатываются варианты озвучки текущего шаблона; видны название файла и процент, есть отмена.
3. Первый запуск устанавливает окружение и скачивает модель. Нужны интернет и установленный **Python 3.11 x64**, с галочкой **Add Python to PATH**. Если Python не найден, приложение сообщит об этом. Скачать: https://www.python.org/downloads/windows/ . Ollama, API-ключи и оплата распознавания не нужны.
4. Нажать «Готово», выбрать привычный стиль субтитров и собрать ролик. Если этот шаг пропущен, при включённых субтитрах недостающие таймкоды создаются во время сборки автоматически.

Файлы озвучки не отправляются в облако и не перезаписываются. Интернет нужен для первоначального скачивания зависимостей и модели, после подготовки распознавание выполняется локально на CPU. Текст и границы слов могут содержать ошибки распознавания: проверьте результат в предпросмотре. Для тишины выдаётся сообщение «Речь не найдена», текст не придумывается.

## Совместимость и хранение

- Существующие корректные ElevenLabs `.timing.json` продолжают использоваться с приоритетом. Повторная генерация голоса не нужна.
- Новые результаты хранятся в папке данных приложения `subtitles/cache/<sha256-аудио>.json`, а не рядом с исходной озвучкой. В них сохранены распознанный текст, язык, источник и границы слов.
- Повторная сборка использует кэш. После обрезки или замены аудио его хеш меняется, старые таймкоды не подставляются к новому файлу. Повреждённый кэш можно получить заново через распознавание; старые материалы не удаляются.
- Стили, цвета, плашки, активное слово и караоке работают через прежний рендерер. Во второй и следующих сценах сдвигаются вместе и фразы, и слова.
- Смена оформления и фоновый предпросмотр не запускают распознавание. Оно запускается явной кнопкой или при сборке с включёнными субтитрами.
- Одна очередь распознавания на приложение ограничивает нагрузку. При пакетной подготовке модель загружается один раз на пачку. При отмене уже готовые результаты остаются, незавершённое задание можно повторить.
- Если распознавание «Нарезчика» уже установлено, подготовка использует его Python и папку моделей; настройки и Ollama нарезчика не меняются.

## Установка агентом на ПК

1. Остановить задачи и закрыть VideoBatch. Сохранить незакоммиченные локальные изменения.
2. Подтянуть main: `git fetch origin main`, `git switch main`, `git pull --ff-only origin main`.
3. Собрать: `dotnet build VideoBatch.csproj -c Release -p:ApplicationIcon=`.
4. В фактической установленной папке приложения обновить **`bin/Release/net48/VideoBatch.exe`**, его config и DLL, а также **всю `tools/subtitles`**. Можно взять артефакт **VideoBatch-Imported-Audio-Update** workflow **Imported audio subtitles**. Это обновление существующего комплекта, не полный portable-архив: сохранить Node, FFmpeg, tools/uploader, аккаунты, шаблоны, историю и медиа.
5. Не использовать старый EXE из корня репозитория. Для этой задачи JS публикации менять не требуется.
6. Проверить Python 3.11 x64. Один раз подготовить распознавание кнопкой в приложении. Для подготовки агентом вручную:

   ```powershell
   .\tools\subtitles\prepare.ps1 -Root "$env:LOCALAPPDATA\VideoBatchDesktop\subtitles" -SharedRoot "$env:LOCALAPPDATA\VideoBatchDesktop\highlights"
   ```

   Если папка данных приложения настроена иначе, использовать её реальный путь вместо стандартного LOCALAPPDATA.
7. Проверить один импортированный MP3 без `.timing.json`, затем две сцены с разной озвучкой. Повторить сборку: распознавание повторяться не должно. Подписи, аккаунты и ранее созданные ролики не удалять.

## Автопроверки

`.github/workflows/imported-audio-subtitles.yml`: Python-тесты границ слов, пауз, тишины, пачки и защиты исходника; Windows-сборка; реальная установка модели без Ollama; кэш и совместимость ElevenLabs; C# → Python → настоящий CPU ASR для MP3/M4A/WAV на английской и синтетической русской речи; экспорт MP4 с субтитрами двух сцен; перестроение после обрезки; работа кэша без повторной подготовки; проверка тишины; скриншоты нативного интерфейса. Тесты не вызывают платные API и не работают с аккаунтами пользователя.

Источник движка и режима word_timestamps: https://github.com/SYSTRAN/faster-whisper . Английский тестовый звук: https://github.com/openai/whisper/blob/main/tests/jfk.flac . Русский тестовый звук создаётся локально eSpeak NG и не выдаётся за запись человека.
