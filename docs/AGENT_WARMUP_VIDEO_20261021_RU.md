# Прогревочные ролики — обновление 21.10.2026

Ветка `feat/warmup-audio-length-20261021`, основана на main `6e6914e` с последними исправлениями Studio. Изменён только генератор прогревочных роликов и его экран. YouTube/TikTok, Telegram, аккаунты, прокси, публикация и действующие настройки не сбрасываются.

## Установить

1. Остановить задачи, закрыть VideoBatch. Сохранить резервную копию EXE/DLL и пользовательских настроек по принятой схеме установки. Не удалять пользовательские данные.
2. Скачать `VideoBatch-Warmup-Update` из успешного Actions «Warmup video audio duration» для этой ветки. Заменить EXE и DLL/подпапку runtimes целиком из архива в текущей установке. Это обновление существующей установки: её `tools` и все работники оставить. Не запускать из распакованной временной папки как новую установку.
3. Либо собрать ветку: `git fetch origin`, `git switch feat/warmup-audio-length-20261021`, `git pull --ff-only`, `dotnet build VideoBatch.csproj -c Release -p:ApplicationIcon=`. При локальных изменениях сначала сохранить их; не делать reset/clean. Из `bin/Release/net48` перенести EXE/DLL/runtimes в установленное приложение.
4. Проверить, что приложение находит **оба** `tools/ffmpeg.exe` и `tools/ffprobe.exe`. Механизм поиска существующий, `ToolsLocator`/`AppPaths`; не создавать отдельные копии исходных видео. В настройках нужны действующие ключи **OpenRouter** и **ElevenLabs**, модель OpenRouter уже берётся из настроек.

## Проверить на ПК

- Раздел «Прогревочные ролики»: RU/EN, «Фон → Выбрать» открывает **файл** фото или видео. Выбранный кадр виден справа; у видео это первый кадр. Папки вместо файла не нужны. Если прежде была выбрана папка, выбрать один фон заново. Старые поля сохранены, аккаунты не затрагиваются.
- Тема анекдота и количество сохраняются автоматически. RU/EN хранятся отдельно. Выбранный файл остаётся по прежнему пути и не копируется. Фон заполняет 1080×1920 с центральным кадрированием; короткое видео зацикливается, его исходный звук исключён.
- Папка по умолчанию: системные «Видео» → `VideoBatch/Прогрев`. Старый стандартный путь `Warmup-RU/EN` заменяется этим; ранее выбранная собственная папка сохраняется. Кнопка «Изменить» задаёт другую папку; «Результаты» её открывает.
- Выбрать один ролик и создать. Нейросеть получает задачу на законченный короткий анекдот, ориентир 6–7 секунд. ElevenLabs озвучивает `eleven_multilingual_v2`, случайный голос из первых 100 доступных голосов аккаунта. Реальная длительность измеряется **после декодирования** MP3, без задержки MP3-кодера.
- Готовый MP4 длится по озвучке, максимум **10 секунд**, без добавленных полусекунд, ускорения и обрезки речи. Кадровая сетка 30 fps допускает техническое округление до одного кадра, до 10 секунд включительно.
- Если речь >10 с, запросить сокращённый законченный анекдот и озвучить повторно. Всего не более **3 озвучек на ролик**, дополнительные попытки расходуют кредиты API. После третьего превышения остановка с понятной ошибкой; уже готовые ролики остаются. Не заменять это обрезкой `-t 10` по длинной речи.
- При остановке недоделанный MP4 удаляется. Ранее готовые ролики не перезаписываются — имена уникальные. В выходной папке только MP4, промежуточные MP3/WAV удаляются. Журнал показывает этап и измеренные секунды; ключи и ответы с секретами в журнал не писать.

## Субтитры

В том же разделе: галочка «Субтитры» и «Настроить» открывает редактор **внутри карточки**. Сохраняются отдельно для RU/EN: шрифт (Segoe UI/Arial/Tahoma), размер, положение сверху в процентах, число слов в одном фрагменте, форма плашки (скруглённая/прямая/без плашки), плотность, цвета текста и плашки. Справа — пример оформления, а не расшифровка уже сгенерированного анекдота.

Субтитры автоматически получаются из озвученного текста через [ElevenLabs with-timestamps](https://elevenlabs.io/docs/api-reference/text-to-speech/convert-with-timestamps): используем `normalized_alignment` или `alignment`. Это один запрос озвучки с таймкодами, отдельная транскрибация не нужна. Времена не угадываются по количеству слов. Если таймкоды отсутствуют/некорректны, выдаётся ошибка, а не фиктивные титры. При отключённых субтитрах используется обычный TTS. Субтитры встраиваются прямо в MP4; внешних SRT/PNG в результатах нет. Пример в предпросмотре и титры результата рисуются одним механизмом.

## Автопроверка для агента

Ветка содержит Windows CI `.github/workflows/warmup-video.yml`: сборка net48, настоящая сборка FFmpeg с фото и видео, дробная длина озвучки, граница 9.999 с, повтор после длинной озвучки, неверный фон до платного запроса, ошибки API, отмена, уникальные имена, синхронизация и реальное встраивание титров, цвета/формы плашек и сохранение настроек. Ответы API в CI подменены: платных запросов нет.

После сборки локальная проверка в **Windows PowerShell 5.1**, в изолированной тестовой папке:

```powershell
$asm = [Reflection.Assembly]::LoadFrom((Resolve-Path bin/Release/net48/VideoBatch.exe).Path)
$ffmpeg = [string](Get-Command ffmpeg.exe).Source
$ffprobe = [string](Get-Command ffprobe.exe).Source
if (!$asm.GetType('VideoBatch.WarmupVideoTests').GetMethod('RunIntegrationTests').Invoke($null,@($ffmpeg,$ffprobe))) { throw 'Media pipeline failed' }
if (!$asm.GetType('VideoBatch.WarmupVideoTests').GetMethod('RunUiTests').Invoke($null,@([IO.Path]::GetFullPath('artifacts/warmup-ui')))) { throw 'UI failed' }
```

Для установленных FFmpeg вместо `Get-Command` можно указать полные пути. Тесты используют временные файлы и поддельные ключи, не выполняют публикацию и не открывают аккаунты. Для настоящего запуска после CI всё равно нужен один контрольный ролик с ключами пользователя: баланс, права, доступность голосов и качество анекдота проверяются только живым запросом.

## Если не работает

- **Выберите файл фона / неверный файл**: проверить наличие исходника и его декодирование. До обращения к платным API проверяется первый кадр. Не подставлять молча чёрный фон.
- **HTTP 401/403**: проверить отдельные ключи/права OpenRouter и ElevenLabs в настройках. **402** — баланс, **429** — лимит. Секреты не копировать в отчёт и не коммитить.
- **Пустой список голосов**: дать ключу ElevenLabs доступ к списку голосов и TTS. Не ставить случайные чужие voice_id.
- **Дольше 10 секунд после 3 попыток**: упростить тему. Лимит не повышать и голос не ускорять.
- **Нет предпросмотра**: проверить FFmpeg и файл; предпросмотр берётся из выбранного исходника, не из браузера/Dolphin.
- При другой ошибке сохранить текст этапа/ошибки, SOURCE_COMMIT и результат автотеста; не менять прокси, профили, сессии и загрузчик Studio ради генератора.

Официальные API: [ElevenLabs TTS](https://elevenlabs.io/docs/api-reference/text-to-speech/convert), [List voices](https://elevenlabs.io/docs/api-reference/voices/search), [OpenRouter Chat API](https://openrouter.ai/docs/api/reference/overview), [FFmpeg](https://ffmpeg.org/ffmpeg.html).
