# Обновление Telegram и общей оболочки — 16.10.2026

Ветка: `feat/telegram-polish-20261016`. Основа: main `6f5c5ca411f20ce55afb9b4aa579f21f770ada2e`.

## Что устанавливается

- Один пункт меню «Профили» для YouTube/TikTok: существующий список профилей, карточки аккаунтов и диагностика сети внутри одного раздела. Источник профилей — существующие каналы YouTube/TikTok в общих настройках, без повторного импорта. Настроенный прокси подтягивается из Dolphin автоматически при открытии списка (общий предел получения 25 секунд, без запуска браузеров); не полученные сведения помечаются явно. Карточка показывает этот прокси, если вручную он ещё не заполнен. Авторизационные данные браузера не извлекаются, ручные секреты не перезаписываются.
- В прежних панелях профилей и сети три элемента были размещены с Dock=Fill поверх друг друга. Теперь фильтры, список и действия занимают отдельные строки и не закрывают данные.

- Общая палитра старых и новых диалогов, тёмные поля ввода и общие кнопки с единым оформлением, читаемым отключённым состоянием и фокусом клавиатуры.
- Общая шапка: элементы выровнены по центру, кнопки не обрезаются; поиск показывается в разделах, где он работает. Убран повтор названия платформы. Боковое меню перестраивается без пустот от скрытых разделов.
- Telegram: компактная таблица, имя и username вместе, страна/заметка в карточке и подсказке, дополнительные действия прокси в меню «Ещё». Двойной щелчок по прокси больше не меняет его назначение случайно.
- Проверка прокси: реальный авторизованный туннель до Telegram, единый предел 7 секунд, отдельная ошибка формата. Проверка аккаунта: общий предел 22 секунды на подключение, авторизацию и получение пользователя, вместо трёх последовательных ожиданий до 35 секунд каждое. Открытие туннеля не выдаётся за подтверждение аккаунта.
- «Открыть Telegram»: выбранная импортированная сессия автоматически подтверждает QR официального Telegram Web A. Дополнительный обязательный клик убран. Сохраняется отдельный браузерный профиль для каждого аккаунта. При ошибке есть «Повторить вход»; 2FA вводится вручную на официальной странице. Недействующая сессия не восстанавливается из одного JSON, не содержащего ключа авторизации.
- YouTube: убраны широкие клики по кнопкам «OK/Принять» на всей странице и принудительные клики по перекрытым элементам. При распознанной рекламе автоматические действия останавливаются для ручной проверки. Новые вкладки из рабочего окна закрываются; переходы основной вкладки на посторонние сайты блокируются. Существующие вкладки профиля не закрываются этим фильтром.
- «Стоп» отдельно показывает завершённые, прерванные, не запущенные задачи и ошибки; остановка не превращается в сообщение «0 аккаунтов прошли прогрев». Частичный запуск не считается завершённым просмотром. Дополнительная имитация человека/рандомизация для накрутки не добавлена.

## Установка агентом на ПК

1. Закрыть VideoBatch. Сохранить копию установленной папки, текущие настройки приложения и `%LOCALAPPDATA%\VideoBatchDesktop\telegram`. Не выводить содержимое vault, JSON, TData и прокси в отчёт или публичные логи. Не удалять `web` и не сбрасывать сессии.
2. В рабочем репозитории выполнить `git status --short`. Если есть локальные изменения — сохранить их отдельным коммитом/веткой, не использовать `reset --hard`.
3. Выполнить:
   ```powershell
   git fetch origin
   git switch --track origin/feat/telegram-polish-20261016
   ```
   Если локальная ветка уже существует: `git switch feat/telegram-polish-20261016`, затем `git pull --ff-only`. Не переносить поверх этой ветки старый EXE или старые Python/JS workers.
4. Проверить GitHub Actions **Telegram workspace** на точном коммите ветки. Скачать из успешного запуска артефакт **Telegram-Workspace-Update** и распаковать в установленную папку целиком. Заменить EXE, управляемые DLL, оба каталога `runtimes/win-x86/native` и `runtimes/win-x64/native`, `tools/telegram`, обновлённые JS в `tools/uploader`. Оставить существующие `node.exe`, `node_modules`, FFmpeg, пользовательские настройки/материалы. Файл `SOURCE_COMMIT.txt` должен совпадать с установленной версией. Одного EXE недостаточно.
5. Альтернатива сборки: `dotnet build VideoBatch.csproj -c Release`, затем установка полного `bin/Release/net48` с runtime DLL и актуальными папками workers. Нужен Microsoft Edge WebView2 Runtime. Для Telegram — Python 3.11 x64 и «Настройки → Подготовить Telegram», если компоненты ещё не установлены.

## Обязательная проверка на настоящем ПК

Автотесты используют синтетические сессии/локальные серверы. Они не подтверждают работоспособность купленного аккаунта или конкретного внешнего прокси.

1. Открыть Telegram → Прокси. Выбрать нужный прокси, проверить протокол HTTP/SOCKS5, адрес, порт, логин/пароль. «Проверить» должен дать либо доступный туннель, либо конкретную причину. Проверка доступности сайта в браузере не доказывает доступность IP дата-центра Telegram. Не подменять протокол и не отключать прокси автоматически.
2. На вкладке аккаунтов назначить этот прокси выбранному аккаунту → «Проверить выбранные». Зелёное состояние появляется только после ответа Telegram `get_me`. При повторном таймауте собрать безопасный код ошибки и этап, время проверки; проверить тот же адрес/протокол в официальном клиенте/у провайдера. Не объявлять прокси исправным по одному открытому TCP-порту.
3. «Открыть Telegram»: дождаться загрузки QR и автоматического подтверждения. При 2FA ввести пароль самостоятельно. Проверить имя/username открытого аккаунта, закрыть окно и открыть снова: профиль должен сохраниться. Отозванная/заблокированная сессия должна давать ошибку, а не чужой/пустой аккаунт. Не импортировать посторонние QR и не переносить auth key в localStorage страницы.
4. Проверить главное окно на 1100 и 1280 px и на используемом пользователем масштабе Windows. Кнопки и тексты не должны обрезаться; Telegram/YouTube/TikTok/монтаж используют общую шапку и общие кнопки. Специальные редакторы каждого раздела не переписаны полностью.
5. YouTube: убедиться, что на рекламе нет повторяющихся кликов и новых рекламных вкладок. Приложение останавливает автоматические действия, а не пропускает рекламу любой ценой. Проверить «Стоп» до запуска профиля и во время работы: соответствующие категории результата, без ложного успеха. Автотесты не доказывают распознавание любой будущей разметки рекламы YouTube; не возвращать общие селекторы кнопок, координатные или force-клики.
6. В отчёте указать установленный SHA, исход каждого пункта, безопасный код/этап ошибки. Не писать «всё работает», если проверены только сборка и тестовые данные.
