# Агенту: установить «Нарезчик»

Ветка `feat/smart-highlights-20261015`, репозиторий `Egorka-777/myvideopril`. Раздел **Контент → Нарезчик**, в стиле приложения. Ветка содержит актуальную main и прежние исправления студии/превью.

## Обновить приложение

1. Закрыть приложение. Сделать резервную копию установки и `%LOCALAPPDATA%\VideoBatchDesktop`. Сохранить settings.xml, аккаунты, vault, историю комбинаций, шаблоны и материалы.
2. В отдельной папке:

```powershell
git clone --branch feat/smart-highlights-20261015 --single-branch https://github.com/Egorka-777/myvideopril.git myvideopril-highlights
cd myvideopril-highlights
dotnet build VideoBatch.csproj -c Release -p:ApplicationIcon=
```

3. Перенести `bin\Release\net48\VideoBatch.exe`, config и **всю** папку `tools\highlights` в установку. Python-скрипты также копируются сборкой в bin. Сохранить имеющиеся tools/ffmpeg.exe, ffprobe.exe, Node и uploader. Если пропущено предыдущее обновление студии, перенести также актуальные JS из tools/uploader и выполнить `npm ci --prefix tools/uploader`. Не трогать данные пользователя и не накатывать старую main поверх этой версии.
4. Установить **Python 3.11 x64** с python.org и **Ollama** с ollama.com/download/windows. Открыть Ollama. Желательно 8 ГБ свободного места для окружения/моделей/кэшей и 8–16 ГБ свободной ОЗУ. Видеокарта не обязательна: распознавание CPU int8, Ollama может использовать поддерживаемую GPU.
5. Открыть **Нарезчик → Подготовка → Подготовить**. Создаётся изолированный Python в пользовательских данных, ставятся закреплённые зависимости, скачиваются Whisper small (многоязычная) и gemma3:4b (смысл + изображения). Нужен интернет, скачивается несколько ГБ. При сбое повторить подготовку; кэш загрузок сохраняется. PyAV закреплён на совместимой версии: свежая 19 несовместима с faster-whisper 1.2.1.
6. Выбрать видео, режим «Авто», число моментов и «Найти моменты». Число — верхняя граница, а не обещание случайных фрагментов. Просмотреть карточки, уточнить секунды «от/до», сохранить выбранные в свою папку. «Результаты» открывает её.

## Поведение

- Длительность 20–40 секунд. Слова с временами faster-whisper группируются по предложениям/длинным паузам. Модель выбирает законченные утверждения с объяснением, выводы и цитаты с проверкой окружающего контекста. 50-секундное предложение не режется посередине ради лимита. Начало вроде «Он означает…» автоматически расширяется предыдущим предложением, если оно помещается в лимит, иначе отбрасывается. Человек всё равно проверяет смысл.
- Авто анализирует речь и длинные участки без речи. «Сильные мысли и цитаты» пропускает визуальный проход; «События без речи» пропускает распознавание.
- Для событий модель получает последовательности кадров раз в 2 секунды, ищет начало/действие/результат. Тайминги приблизительны; быстрые события могут быть пропущены. Это не понимание каждого кадра и не гарантия вирусности. На CPU визуальный проход может быть долгим.
- При пустом отборе/ошибке модели нет подмены случайной нарезкой. Отклоняются выдуманные ID, неправильные времена, незаконченные/низко оценённые кандидаты, перекрытия и точные повторы текста.
- Анализ обращается только к 127.0.0.1:11434. Ключи и платные API не используются; источники не отправляются в облако. Runtime распознавания использует только скачанную модель. Проверить, что в Ollama gemma3:4b — обычная локальная модель, а не пользовательский облачный псевдоним.
- «Просмотр» создаёт один временный отрывок и открывает стандартный видеоплеер Windows. Экспорт через FFmpeg с перекодированием ради точного начала, с исходным звуком и соотношением сторон. HDR отклоняется с подсказкой перевести в SDR. Автокадрирование 9:16 и субтитры не входят в эту версию.
- Исходник читается на месте, не копируется и не меняется. Проверяется SHA256; если источник изменился после анализа, нужно повторить поиск. Повторный экспорт не перезаписывает старые результаты. Неудачный промежуточный MP4 и временные WAV/кадры удаляются.
- Настройки и последние карточки восстанавливаются. Кэш расшифровок по SHA256: `VideoBatchDesktop\highlights\cache`; последний результат: `highlights\last-result.json`. При закрытой программе можно удалить `highlights\cache` и `highlights\preview` для освобождения места. Модели/venv удалять не нужно.
- Диагностика в общих `diagnostics\app-*.jsonl`; текст расшифровки не пишется в общий лог. Отмена прекращает обработчик и FFmpeg, готовые отрывки остаются. Уже запущенный Ollama может продолжить скачивание при отмене подготовки — остановить его можно в Ollama.

## Обязательная проверка на ПК

1. Подготовить модели, затем повторить анализ без интернета. Не должно быть оплаты/ключей и отправки файлов наружу.
2. Протестировать реальное русское видео Егора: 20–40 секунд, первый/последний слог цел, пояснение и оговорки не потеряны. Оценка качества на его материале не заменяется CI.
3. Ролик без речи и смешанный; отмена поиска/экспорта; закрытие во время работы; повторный запуск с карточками; сохранение в путь с кириллицей/пробелами.
4. Убедиться, что исходники неизменны, экспорт не дублируется в другие папки, результат открывается кнопкой.
5. Проверки CI `Highlights cutter`: Windows сборка/UI/скриншоты и `tests/highlights_test.py` (контракты + настоящий экспорт/первый кадр FFmpeg). Это не тесты качества модели.
6. Отдельный job `local-models`: `tests/highlights_models.py` действительно скачивает small и gemma3:4b, выполняет ASR, смысловой отбор и обработку изображения. Его отчёт — отдельный artifact. При сетевом/ресурсном сбое не выдавать fixture-тесты за проверку нейросети; повторить реальный прогон на ПК. Скрипт CI запускает собственный Ollama-сервис; перед ручным прогоном остановить другой сервис либо использовать отдельную тестовую машину.

## Бесплатность

Faster-whisper — MIT, без оплаты за минуты и подписки при локальном запуске. Ollama работает на ПК; у Gemma собственные условия использования на странице модели. Нужны место, ресурсы ПК и интернет для первого скачивания. Платные API не подключены.
