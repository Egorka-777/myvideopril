# Аккаунты — личная картотека

Раздел «Аккаунты» — карточки социальных аккаунтов и их сведения. При открытии он подтягивает существующие строки из YouTube/TikTok. «Профили браузера» — отдельный технический раздел: один такой профиль может использоваться для нескольких каналов. Настройки загрузки, сессии, расписания и сборка роликов остаются в своих разделах.

## Уже добавленные аккаунты

Карточки создаются при открытии «Аккаунтов». Подтягиваются название, площадка, RU/EN, сохранённая ссылка YouTube и связь с профилем браузера. IP из настроек показывается отдельно: это не строка прокси. Данные для входа, страна, полный прокси и ссылка на покупку, которых нет в настройках загрузки, остаются пустыми. На карточке написано **Не заполнено**, кнопка **Дополнить** открывает ручное заполнение.

Повторное открытие не создаёт копии связанных карточек. Ранее заполненные вручную данные сохраняются. Существующая ручная карточка связывается по однозначному совпадению ссылки и площадки; одинаковое название или профиль браузера не доказывают, что это один аккаунт. При неоднозначном совпадении раздел сообщает количество несвязанных строк. У разных ссылок YouTube не будет общей карточки только из-за одинакового профиля браузера. Если один канал явно указан в RU и EN, карточка показывает оба списка.

Кнопки списка на карточке открывают соответствующую строку YouTube/TikTok. Связь работает из рабочих списков в картотеку: редактирование карточки не меняет настройки загрузчика и браузера.

В YouTube/TikTok правой кнопкой → **Убрать из списка RU/EN** удаляется выбранная строка только из текущего рабочего списка. Другие списки, браузер и файлы сохраняются. Карточка с ручными данными остаётся и отмечает, из какого списка аккаунт убран. В «Профилях браузера» отдельное действие **Убрать из всех рабочих списков…** относится ко всем связанным строкам и имеет отдельное подтверждение.

## Быстро начать

1. Нажми **+ Аккаунт**.
2. **Канал**: название, ссылка, YouTube/TikTok, RU/EN, статус и страна. Обязательно только название; остальные поля можно заполнить позже.
3. **Вход и прокси**: логин/почта, пароль, дополнительные данные для входа и строка прокси целиком. Раздел ничего не проверяет в интернете и не запускает вход в аккаунт.
4. **Покупка и заметки**: ссылка на заказ/продавца и всё, что стоит помнить, например дату покупки, контакты продавца или причину блокировки.
5. Нажми **Сохранить**. Для исправлений выбери карточку → **Изменить**.

Слева — список с названием, площадкой, языком, страной и цветным статусом. Сверху — поиск и три фильтра. Поиск учитывает название, ссылку, страну, логин, заметки и продавца; пароль, прокси и дополнительные секретные данные в поиске не участвуют. Можно ввести несколько слов.

В карточке есть кнопки **Открыть** и **⧉** для копирования конкретного поля. Статус меняется прямо в карточке и сразу сохраняется: Рабочий, Проверить, Не работает, Заблокирован, Архив. Ручную несвязанную карточку можно удалить после подтверждения. Для связанной карточки удаление рабочего аккаунта выполняется в его списке; карточка сохраняет сведения.

## Перенести Excel

Поддерживается **.xlsx**, установка Excel не требуется. Если файл старого формата .xls или защищён паролем, сначала сохрани обычную копию .xlsx.

1. Нажми **Из Excel** и выбери файл.
2. Выбери вкладку. Площадка и RU/EN предлагаются по названию вкладки, их можно исправить.
3. Проверь строку заголовков: список показывает реальные номера строк Excel.
4. Проверь, каким полям соответствуют столбцы. Для ненужных полей оставь **Не использовать**. Если логин, пароль и прочее записаны одной строкой, назначь этот столбец полю **Данные для входа (целиком)** — содержимое сохраняется без разбиения.
5. Проверь названия, ссылки и страну в предпросмотре → **Добавить аккаунты**.
6. Повтори для других вкладок: YouTube RU, YouTube EN, TikTok RU, TikTok EN.

Строки без названия пропускаются с подтверждением. При повторном импорте уже существующие карточки не перезаписываются: для той же площадки и языка сравнивается ссылка; если ссылки нет — название и логин. Для обновления существующей карточки используй «Изменить». Неизвестный статус сохраняется в заметках, в карточке ставится «Проверить». Столбец с отметкой «рабочий / не рабочий» нужно назначить полю «Статус». Ссылки должны содержать http:// или https://. Обычные Excel-гиперссылки читаются по адресу, а не только по тексту «Открыть». Макросы и формулы не запускаются; используется сохранённое значение ячейки. Пароль с ведущими нулями сохраняется, если в Excel он записан текстом.

Импорт ограничен 20 000 строками на вкладку, 256 столбцами и 40 МБ на XML-часть. Таблица пользователя в репозиторий не загружается.

## Сохранение и приватность

Все данные картотеки, включая названия и ссылки, шифруются Windows DPAPI для текущего пользователя. Файл: `%LOCALAPPDATA%\VideoBatchDesktop\accounts.vault`. При обновлении автоматически сохраняется предыдущая зашифрованная версия `accounts.vault.bak`. Запись атомарная; параллельные экземпляры приложения читают актуальный файл перед изменением. Ошибка чтения блокирует изменение, повреждённый файл не заменяется пустым.

В карточке вход и прокси скрыты до **Показать данные**. Через минуту они снова скрываются; также при смене карточки/раздела и потере активности основного окна. После копирования секретного поля приложение через 45 секунд очищает буфер, если его содержимое с тех пор не изменилось. Windows или отдельная программа могут самостоятельно сохранять историю буфера обмена — приложение такую историю не удаляет.

Шифрование привязано к пользователю Windows. Копии vault и bak подходят для восстановления на том же компьютере под тем же пользователем; обычное копирование на другой ПК не является переносом доступа. Исходный Excel можно оставить как независимый источник для переноса. Восстановление выполняй при закрытом приложении: сохрани оба текущих файла, затем при необходимости скопируй `accounts.vault.bak` в `accounts.vault`.
