# ClipFlow — передача проекта

**Макет НЕ финальный.** Это материалы для самостоятельного аудита и следующей итерации дизайна, а не утверждённый интерфейс.

1. Начать с [HANDOFF_RU.md](HANDOFF_RU.md) — контекст, требования, задача агенту.
2. [Интерактивный прототип](prototype/ClipFlow.html) — скачать HTML и открыть локально в браузере.
3. [Аудит](prototype/UX-AUDIT.md) — предварительная карта существующих функций.
4. [Предыдущая спецификация](prototype/AGENT.md) —Справочная версия, не окончательное ТЗ.
5. [UI-TEST.py](prototype/UI-TEST.py) — исходный тест прототипа (Playwright, Chromium).

Ветка создана от main; код приложения не изменён. Исходные скриншоты и архив не включены: репозиторий публичный, а доступный интерфейс передачи файлов не предоставляет байты ZIP/PNG. HTML и Markdown перенесены из предыдущего комплекта. Макет не выполняет настоящий AI-анализ, рендер или публикацию. Проверить актуальную версию приложения и заново пройти пользовательские цепочки перед дальнейшей разработкой.
