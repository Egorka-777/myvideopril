VideoBatch 4.0.2 — обработка видео, очередь Dolphin и расписание YouTube

ЗАПУСК

1. Распакуйте архив целиком в новую папку.
2. Откройте VideoBatch.exe. Установка и команды не нужны.

ОБРАБОТКА ВИДЕО

Добавьте видео, выберите короткий или обычный режим, количество 1–10
и нажмите «Создать видео». Все варианты, сжатие, формат, битрейт,
частота кадров, метаданные и даты подбираются автоматически.

Для обычных видео кнопка «Фон» добавляет разные музыкальные отрывки
поверх речи. Громкость по умолчанию −7,5 дБ.

Музыка и фон разделены по рынкам: «Русские» и «English»
(в окне «Музыка…» / «Фон…»). Уже добавленные ранее треки считаются
русскими. Для зарубежных роликов переключите рынок на English и
загрузите отдельный список.

ЗАГРУЗКА YOUTUBE ЧЕРЕЗ DOLPHIN

Нажмите «YouTube через Dolphin →». Дальше окно ведёт по четырём шагам:

1. DOLPHIN
Запустите Dolphin Anty. В личном кабинете Dolphin на сайте создайте
API-токен и вставьте его в «1. Dolphin…». Локальный порт смотрите
в окне Health приложения Dolphin; обычно это 3001.
Токен сохраняется в Windows зашифрованно.

2. КАНАЛЫ
Добавьте строку для каждого канала. Вставьте Profile ID из Dolphin,
выберите видео, введите заголовок и при желании выберите превью.
Название канала в таблице — только удобная подпись.
Прокси в VideoBatch вводить не нужно: используется прокси выбранного
профиля Dolphin вместе с его cookies и Google-сессией.

Сверху переключатель «Русские / English»: это два отдельных списка.
Новый канал попадает в текущий рынок. Заголовки, поиск и пачка шортсов
действуют только на видимый рынок — английские и русские не смешиваются.
В столбце «Рынок» канал можно перенести (RU ↔ EN).

Тип строки «Длинное / Шортс» и кнопки «Заголовки длинных…» /
«Заголовки шортсов…» раздельные. Пачка шортсов помечает строки как шортсы.
При «Загрузить выбранное» в YouTube уходит текст из столбца
«Заголовок → YouTube» каждой отмеченной строки.

3. ПРОВЕРКА
Нажмите «Проверить профили». Каждый профиль запускается отдельно.
Сначала открывается YouTube через прокси профиля (главный признак, что
прокси жив), затем внешний IP узнаётся несколькими сервисами через
fetch — не только ifconfig.me. IP сравнивается с прямым IP компьютера,
затем профиль закрывается. Одинаковые IP считаются возможным запуском
без прокси, поэтому проверка останавливается. Безопасный IP сохраняется.

4. ЗАГРУЗКА
Нажмите «Загрузить выбранное». Перед открытием YouTube внешний IP
проверяется ещё раз. При несовпадении, неработающем прокси или ошибке
Dolphin YouTube не открывается. Загрузка идёт строго по одному каналу.
Для каждого ролика приложение само выбирает «Запланировать», ставит дату
и время, сохраняет ролик, закрывает профиль и переходит к следующему.

Авторасписание начинается завтра в 12:00, шаг — 30 минут. После 21:30
следующий ролик переносится на 09:00 следующего дня. Следующие свободные
времена запоминаются, поэтому разные запуски не получают один слот.
Назначенное время сразу показывается в статусе строки и в журнале.

Важно: эти 30 минут относятся только к времени будущей ПУБЛИКАЦИИ.
Между загрузками ждать полчаса не нужно. После успешной загрузки профиль
закрывается, приложение делает случайную паузу от 1 до 30 секунд и запускает
следующий. Первый профиль очереди запускается сразу.

Если для отдельного ролика нужно точное время, добавьте его перед обычным
заголовком в таком виде:
[2026-09-06 18:30] Обычный заголовок ролика
Квадратная часть в YouTube не попадёт — приложение её удалит.

Описание, теги и аудитория берутся из настроек загрузки самого канала.
Видимость принудительно ставится «Запланировать»: до выбранной даты ролик
остаётся закрытым. Если YouTube потребует обязательный ручной выбор,
приложение остановит очередь и оставит профиль открытым.

«Заголовки…» / «Видео по строкам…» / «Пачка шортсов…» крепятся к ОДНОМУ
каналу (в списке не плодятся клоны). Пачка хранится внутри строки канала.
Локальные файлы сразу переименовываются под YouTube-заголовки (чтобы в
Studio не светилось старое имя файла).

Загрузка пачки одного канала: профиль открывается ОДИН раз, ролики
идут подряд без закрытия Dolphin между ними.

Параллельно: пока грузится один канал, кнопка «Загрузить выбранное»
остаётся активной — отметьте другой канал и нажмите снова.

IP: ротация прокси в том же диапазоне / той же стране разрешена.
Блокировка только если страна прокси явно другая.

«Пачка шортсов…»: отметьте ровно один канал, выберите несколько файлов
и задайте заголовки шортсов отдельно (список 1:1 или один общий). Для
каждого файла создаётся своя строка с тем же Profile ID — очередь
загрузки идёт по ним как обычно.

ПОИСК НА YOUTUBE

«Поиск» — ключ/фраза (именно её вводят в поиск YouTube).
«Ссылка» — только ориентир: по video ID найти нужный ролик в выдаче
и кликнуть. Ссылку в поиск НЕ вводят и по ссылке напрямую НЕ открывают.

Фильтр даты по умолчанию «Загруженные сегодня». Если с фильтром пусто —
тот же ключ без фильтра. Дальше: просмотр до конца, лайк в случайный
момент в последние 30 секунд, закрытие профиля.

БАЗА ЗАГОЛОВКОВ

«База заголовков длинных…» / «База заголовков шортсов…» — отдельно для
RU и EN. Один раз вставили список. При выборе видео приложение само
берёт нужное число заголовков сверху (использованные убираются из базы;
если в базе один заголовок — размножается как «… (1)…(N)» и остаётся).

«Видео → каналы…» — несколько файлов, в окне указываете канал для каждого.
Или по очереди: канал → «…» у Видео → отметить все → «Загрузить выбранное»
(несколько профилей параллельно).

TIKTOK

На главном экране кнопка «TikTok» открывает отдельное рабочее пространство
(только короткие). Кнопки простые: Dolphin, + Аккаунт, Из YouTube,
Выбрать видео, Заголовки, Музыка, Проверить, Загрузить.

Заголовки и Описание — две отдельные базы на рынок. При выборе видео
берутся сами. В таблице колонки «Заголовок» и «Описание».
При загрузке воркер заполняет оба поля в TikTok Studio.

YOUTUBE

Кнопка «YouTube» — своё пространство. Выбрать видео, Заголовки,
Заголовки шортс, Пачка шортс, Проверить, Найти, Загрузить.

Во время очереди VideoBatch и Dolphin должны оставаться запущенными.
Окна можно свернуть и работать за компьютером, но полностью закрывать их
нельзя. Окно профиля Dolphin может ненадолго появляться — нажимать в нём
ничего не требуется.

ВАЖНО

Не запускайте нужный профиль Dolphin вручную одновременно с очередью.
Для вращающегося прокси повторно нажмите «Проверить профили» перед серией.
В самом профиле Dolphin рекомендуется запретить прямое WebRTC/UDP.

Нужна Windows 10/11 x64 с .NET Framework 4.8.
Папка tools и VideoBatch.exe.config должны оставаться рядом с EXE.
Приложение не подписано издателем. Автоматизация интерфейса YouTube может
потребовать обновления, если YouTube существенно изменит страницу загрузки.
