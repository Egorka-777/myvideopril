# Telespace — эталон установки

**Источник на ПК:** `D:\Telespace`  
**Дата снимка:** 2026-10-17  
**Ветка:** `ref/telespace-install-20261017`

## Что включено

- `Telespace.exe` — приложение
- `data/` (кроме секретов), `uploads/` — структура каталогов

## Намеренно не в Git (секреты / персональные данные)

Скопируйте локально при отладке, **не пушить**:

| Файл | Зачем нужен агенту локально |
|------|-----------------------------|
| `telespace.db` (+ `-shm`, `-wal`) | SQLite с аккаунтами/настройками |
| `data/.license` | лицензия |
| `data/.session_secret` | секрет сессии приложения |

## Задача для доработки VideoBatch

Сравнить с `tools/telegram` в myvideopril: проверка аккаунта, прокси (SOCKS/HTTP), таймауты, повторы, хранение прокси. Использовать этот эталон как «рабочий» UX подключения, не копируя бинарник в продукт без лицензии.
