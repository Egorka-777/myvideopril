# Reference installs (Telegram desktop tools)

Снимки установленных программ для сравнения с интеграцией VideoBatch (`tools/telegram`).

- Ветка **`ref/telespace-install-20261017`** — `telespace/`
- Ветка **`ref/deskgram2-install-20261017`** — `deskgram2/`

**Не коммитить:** живые `.session`, TData JSON, ключи лицензий, HWID, SQLite с аккаунтами.

Исходные пути на ПК владельца: `D:\Telespace`, `C:\Deskgram2`.
