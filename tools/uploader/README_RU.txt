Модуль YouTube VideoBatch 4.0.2

node.exe и папка node_modules нужны для подключения к уже запущенному
профилю Dolphin через Chrome DevTools Protocol. Отдельный браузер этот
модуль не устанавливает и не запускает.

Не удаляйте и не перемещайте содержимое этой папки.

Модуль автоматически выставляет запланированную публикацию. По умолчанию
слоты начинаются завтра в 12:00 с интервалом 30 минут. Точное время можно
задать префиксом заголовка: [2026-09-06 18:30] Заголовок.

Компоненты:
- Node.js 22.23.2 — https://nodejs.org/
- playwright-core 1.55.0 — https://playwright.dev/

Лицензии находятся в Node_LICENSE.txt и Playwright_LICENSE.txt.
